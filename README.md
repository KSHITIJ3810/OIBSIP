# 📁 Tasks Completed

---

## 🔹 Task 1: Iris Flower Classification

### 📌 Objective

Classify iris flowers into different species based on their features.

### 🧠 Approach

* Loaded dataset using pandas
* Cleaned unnecessary columns
* Used features:

  * Sepal Length
  * Sepal Width
  * Petal Length
  * Petal Width
* Applied **Decision Tree Classifier**
* Compared model prediction with manual rule-based logic

### 📊 Outcome

* Achieved high accuracy
* Understood classification basics
* Learned how models differentiate between categories

---

## 🔹 Task 2: Unemployment Analysis

### 📌 Objective

Analyze unemployment trends, especially during Covid-19

### 🧠 Approach

* Worked with multiple CSV datasets
* Cleaned and formatted date columns
* Used:

  * pandas for analysis
  * matplotlib & seaborn for visualization

### 📊 Visualizations

* Unemployment rate over time
* State-wise unemployment
* Rural vs Urban comparison
* Top states with highest unemployment

### 💡 Learning

* Data visualization
* Trend analysis
* Real-world data handling

---

## 🔹 Task 3: Car Price Prediction

### 📌 Objective

Predict car prices based on multiple features

### 🧠 Approach

* Cleaned dataset
* Converted categorical data using encoding
* Selected features like:

  * Fuel type
  * Mileage
  * Engine specs
* Applied **Linear Regression**

### 📊 Evaluation

* R² Score ≈ 0.59
* MAE ≈ 2

### 💡 Learning

* Regression concepts
* Feature handling
* Model evaluation

---

## 🔹 Task 4: Email Spam Detection

### 📌 Objective

Classify emails as Spam or Not Spam

### 🧠 Approach

* Processed text data
* Converted text → numerical using **CountVectorizer**
* Applied **Naive Bayes Classifier**

### 📊 Outcome

* High accuracy (~95%+)
* Successfully classified spam messages

### 💡 Learning

* Natural Language Processing basics
* Text vectorization
* Classification using probabilities

---

## 🔹 Task 5: Sales Prediction

### 📌 Objective

Predict product sales based on advertising budget

### 🧠 Approach

* Used dataset with:

  * TV Ads
  * Radio Ads
  * Newspaper Ads
* Applied **Linear Regression**

### 📊 Outcome

* Strong R² Score (~0.85+)
* Accurate predictions

### 💡 Learning

* Relationship between advertising & sales
* Business-oriented ML application
